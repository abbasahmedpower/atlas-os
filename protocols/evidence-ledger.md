# Evidence ledger
For every important assertion use: Claim ID | statement | origin (official docs/source/test/assumption) | version/date | reproducible command/line | verification status [VERIFIED, CORROBORATED, HYPOTHESIS, UNKNOWN] | confidence | risks.
A command not executed is UNTESTED even if syntactically plausible. A source cited is not a benchmark. Attach minimal redacted logs or test outputs; remove passwords and identifying tokens. Separate input, observation, inference, recommendation.
A verified result is environment-specific. Record OS, architecture, runtime, dependency versions and exact test invocation. If citations are unavailable, say so.
