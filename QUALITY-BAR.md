# Quality bar: objective, non-magical
An output is NOT 'expert' because it is long. Rate each dimension 0–4: correctness, reproducibility, security, maintainability, performance evidence, accessible teaching, source provenance.
- 0 missing; 1 assertion only; 2 explained; 3 demonstrably tested; 4 independently reproduced on new input.
- Hard gates: no fabricated tool run; no unknown assertion marked verified; no unbounded destructive command; no fake benchmarks; no hidden permissions.
- For every completed bug: baseline failing test, minimal fix, passing regression test, residual risks.
- For every claim about 'best': compare dated alternatives with declared metrics, environment and limitations; otherwise explicitly avoid superlative.
