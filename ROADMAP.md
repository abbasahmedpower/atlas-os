# 24-week spiral roadmap (foundation; not a claim of expertise)

Weeks 1–4: Linux/Windows terminal, Git, Python/C# basics, TCP/IP, packet capture and safe Ncat localhost labs.
Weeks 5–8: OS internals, data structures, concurrency, C fundamentals, robust networking and tests.
Weeks 9–12: secure coding, OWASP WSTG on intentionally vulnerable localhost apps, threat modeling, logging and CI.
Weeks 13–16: PE/ELF, x86-64, Ghidra, debugging self-written binaries, call graphs and dynamic traces.
Weeks 17–20: SOC telemetry, MITRE mappings, incident triage, detection logic, controlled simulations, source-code auditing.
Weeks 21–24: advanced C#/.NET systems project; CI, fuzz/property tests, profiling, architecture review; optional low-voltage embedded telemetry.

Every fortnight: one public portfolio artifact, a bug report, an independent unseen challenge and a retro. Beyond week 24 specialize deeply in one track while maintaining adjacent foundations.
