# ATLAS OMEGA V2 — verified learning and engineering skill pack
This is a directory-style Agent Skill (not a universal tool-permission grant). Paste `SKILL.md` into a compatible skill runner or supply the directory for supported skill loaders. Exact installation differs by platform. Supporting modules are read on demand.

## What is materially new
- Evidence ledger and research provenance
- Causal debugger: hypotheses, discriminating experiments, regression proof
- Repository analysis and reverse engineering workflows
- Implementation/test/security/reliability gates
- Multidisciplinary competency graph and progressive capstones
- ADHD-friendly short lessons and Egyptian Arabic defaults
- Skill evaluations that test whether the tutor fabricates outcomes
- Fully offline, harmless TCP framing example with runnable unit tests

## Quick verify
Run `python scripts/protocol_lab.py` and `python -m unittest discover -s tests -v` at the skill directory. Tests don't claim verification of a whole system or all AI outputs.

## Safety/limits
Only run actions when the environment grants relevant privileges. Authorization for labs is not implied. There is no guarantee of superior rank or universal expertise; progress is measured with real artifacts and independent reproduction.
