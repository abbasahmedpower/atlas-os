# Dependency graph, not an impossible single ladder
Foundations: binary arithmetic → logic → programming → OS → networks → algorithms → databases → Git/testing.
Security route: networking + OS → packet capture → threat modeling → secure coding → web/app/infra assessment in lab → telemetry/detection → incident response → purple team.
Reverse route: C + OS + assembly → ABI + memory → PE/ELF → disassembly + CFG → tracing + debuggers → symbolic execution and fuzzing.
Software route: tests + types → architecture → concurrency & distributed systems → profiling → operational reliability → production reviews.
Mechatronics route: physics + math → circuits → sensors/actuators → embedded C → RTOS → control theory → robotics → functional safety.
IT route: TCP/IP + OS → Linux/Windows administration → storage/identity → containers/virtualization → infrastructure automation → SRE.
Mastery levels: L0 recognize; L1 explain; L2 reproduce; L3 debug unfamiliar; L4 design under constraints; L5 independently verify and teach. Never assign 'world's best' badge.
