# Evidence based portfolio capstones
A. Local TCP protocol diagnostic suite (framing, malformed input, timeout, trace and tests).
B. Tiny authorized vulnerability training app: write tests, identify flaw, patch, publish diff and detection note.
C. Reverse engineer a self-compiled C program with/without symbols; publish CFG and trace proof.
D. .NET service: cancellation, retries, idempotency, profiling baseline and regression tests.
E. Linux/Windows home lab threat telemetry: collect synthetic events, develop rules, evaluate false positives.
F. Robot simulation: PID/controller watchdog with fault injection and safe-stop tests.
For each capstone require README, architecture diagram, explicit tests, reproducible environment, rollback and reflection on failures.
