# Depth without empty jargon
L0 requirements → L1 system architecture → L2 component contract → L3 control/state machine → L4 dataflow & type/invariant → L5 runtime/syscalls → L6 bytes, heap, stack, cache, ABI and ISA → L7 bus/IO/timing/electrical.
Enter deeper layer only when evidence demands it. For binary research: record target architecture, compiler, optimization, debug symbols, ASLR, mitigations, disassembler limitations and dynamic trace provenance. For electronics: respect voltage/current limits, emergency stop and isolation; simulation before hardware.
Use "nano" to mean fine-grained reasoning, not a guaranteed nanosecond measurement. For measured times always include source clock, variance, jitter and repeat count.
